# 中房家 ホームページ

大阪市東淀川区菅原の中華料理・大衆居酒屋「中房家」の公式サイト（静的HTML／WordPress移行前提）。

サイトコンセプト：**「うまいもんを、腹いっぱい。人の温かさまで味わえる、街の中房家。」**

---

## 1. ファイル構成

```
index.html                    トップページ（1ページ完結構成）
css/style.css                 スタイル。冒頭にデザイントークンを集約
js/main.js                    ドロワーメニュー／ヘッダー影／フェードイン のみ
images/placeholder-light.svg  写真差し替え用プレースホルダー（明るい背景用）
images/placeholder-dark.svg   写真差し替え用プレースホルダー（暗い背景用）
images/photos/                実店舗写真の置き場所。固定ファイル名14枚（「4. 写真の割り当て一覧」参照）
```

ローカル確認は任意の静的サーバーで。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 2. デザインの意図（なぜこのデザインなのか）

| 設計判断 | 理由 |
| --- | --- |
| 生成り（#F7F3EA）＋薄い罫のテクスチャをベース | 高級中華の黒×金ではなく「大衆感 × 清潔感」。紙の品書きの手触りを土台にした |
| 赤は暖簾・番号・CTAのみ | 画面全体を赤くせず、行動してほしい場所だけに赤を集中させる |
| ランチ＝明るい生成り／夜＝チャコール | 「昼は定食、夜は居酒屋」という中房家の二面性を、色の明度差で体感させる |
| お品書きを短冊（紙片）レイアウトに | 町中華の壁の品書きが原型。均一なカードの羅列を避け、店の実景に寄せた |
| 選ばれる理由を左右交互＋大きな番号 | 3枚並列カードのテンプレート感を避けつつ、3つの強みを強く印象づける |
| お客様の声は★評価ではなく「評価が集まっている観点」 | 架空の口コミを作らない方針のため。何が褒められている店かだけを伝える |
| スマホ下部固定CTA（電話／アクセス） | 主目的が来店・電話。予約URLが未提供のため、確認できる手段だけを置いている |

## 3. 修正しやすさのルール

- **色・フォント・余白**：`css/style.css` 冒頭の `:root` のカスタムプロパティを変更すれば全体に反映される。
- **店舗情報**：住所・電話・最寄り駅などの本文表記は「アクセス」セクションの `dl.spec` と `footer` に集約。
- **電話番号**：`index.html` 内の `tel:0669905578` と表示用テキスト `06-6990-5578` を検索して一括置換する。
  ```bash
  grep -n "0669905578\|06-6990-5578" index.html
  ```
- **写真**：`images/photos/` の固定ファイル名（下の一覧）に統一済み。**同じ名前の jpg を置くだけで差し替わる**（HTML の編集は不要）。ファイルがない間はプレースホルダーSVGに自動で戻る。
- **見出しの改行**：日本語が語句の途中で折り返らないよう、一部の見出しは `<span class="nb">` で語句を包んでいる（`.nb { display: inline-block }`）。文言を変えるときはこの区切りも合わせて見直す。
- **ファーストビューの写真**：実写を入れたら、`img` の `src` 差し替えとあわせて `.hero__ph-note`（「ファーストビュー写真　差し替え予定」の1行）を削除する。
- **セクション**：`index.html` の各セクションは `<!-- ==== 番号 セクション名（WP: template-parts/...）==== -->` で区切ってある。WordPress化の際はこの単位で `template-parts/` に分割する想定。

## 4. 写真の割り当て一覧（images/photos/）

ページ内の写真枠14か所は、下記ファイル名と 1 対 1 で対応しています。
ファイルを `images/photos/` に同名で置けば、その場所の写真が差し替わります。

| ファイル名 | 掲載場所 | 入れる写真 | 表示比率 |
| --- | --- | --- | --- |
| `hero.jpg` | ファーストビュー背景 | 外観 | 画面全体（cover） |
| `about-staff.jpg` | 中房家とは（大） | 店内・スタッフ | 3:4 |
| `about-exterior.jpg` | 中房家とは（小） | 外観 | 4:3 |
| `reason-food.jpg` | 選ばれる理由 01「うまい」 | 中華料理 | 1:1 |
| `reason-volume.jpg` | 選ばれる理由 02「腹いっぱい」 | ボリュームのある料理・定食 | 1:1 |
| `reason-staff.jpg` | 選ばれる理由 03「人があったかい」 | スタッフ・接客 | 1:1 |
| `menu-main.jpg` | お品書き（主役） | 看板の一皿（炋飯想定） | 4:3 |
| `menu-noodles.jpg` | お品書き（左下） | 麺料理 | 1:1 |
| `menu-ippin.jpg` | お品書き（右下） | 手作りの一品料理 | 1:1 |
| `lunch.jpg` | ランチ | 日替わりランチ・定食 | 4:3（PCは5:4） |
| `night.jpg` | 夜の楽しみ方 | 夜の店内＋料理＋お酒 | 4:3（PCは高さ追従） |
| `scene-solo.jpg` | 店内・利用シーン（大） | 一人利用の雲囲気 | 4:3（PCは21:9） |
| `scene-family.jpg` | 店内・利用シーン（左） | 家族利用の雲囲気 | 1:1 |
| `scene-group.jpg` | 店内・利用シーン（右） | グループ利用の雲囲気 | 1:1 |

### 差し替え手順

1. 写真を上記のファイル名にリネームして `images/photos/` に置く（拡張子は `.jpg`）。
2. ブラウザをスーパーリロード（`Ctrl+Shift+R` / `Cmd+Shift+R`）して反映を確認する。
3. その写真の `alt` から「（写真差し替え予定）」を外し、実態に合った説明にする。
4. ファーストビューを差し替えたときは、`.hero__ph-note`（「ファーストビュー写真　差し替え予定」の1行）を削除する。

推奨サイズの目安：`hero.jpg` は横1600px以上、その他は横1200px程度。
比率は CSS 側で固定して `object-fit: cover` で切り抜くので、縦写真・横写真のどちらでもレイアウトは崩れません（上下または左右がトリミングされます）。
主役を中央寄りにしておくと、どの画面幅でも意図どおりに見えます。

### 写真の優先順位（未受領）

現時点で実店舗写真は未受領のため、14枚すべてプレースホルダー表示です。揃える順番の推奨は以下。

1. `hero.jpg`（外観）― 第一印象を決めるので最優先
2. `reason-staff.jpg` / `about-staff.jpg`（スタッフ）― 中房家最大の差別化要素
3. `menu-main.jpg` / `lunch.jpg`（料理・ランチ）― 来店動機の中心
4. `scene-solo.jpg`（店内全体）― 入りやすさの安心材料
5. 残りの料理・利用シーン

そのほか、ロゴデータ（現在はヘッダーの「中」マーク➕テキストで暫定表示）と、JR淡路駅からの徒歩ルート写真があればアクセスの安心感が上がります。

他店の写真・ストック素材・生成画像を中房家の写真として使用しないこと。

## 5. 店舗への確認事項（サイト公開前に必須）

画面上では `要確認` チップで該当箇所を明示しています。

- 正式な営業時間 / 定休日（掲載媒体によって記載差があるため必ず店舗確認）
- ランチの営業時間・内容・価格
- 現在のお品書き（提供中の料理）と価格
- ドリンク・お酒のラインナップと価格
- 予約方法（電話受付の時間・条件、ネット予約の有無とURL）
- 席数・座敷・個室・宴会・貸切の対応
- 駐車場
- 支払い方法（カード・電子マネー・QR）
- テイクアウトの現在の対応状況
- 郵便番号（Googleマップの掲載では 533-0022 と表示されるが、店舗確認後に反映）
- 公式Instagramアカウント（確認できれば `index.html` の Instagram セクションのコメントを解除）
- 店主様からのごあいさつ文（「中房家とは」の本文を差し替え）
- 掲載可能な口コミ本文と出典（現在は評価の傾向のみ掲載）

未確認の情報は、確定するまで断定表現で書かない方針です。

## 6. WordPress化のときの想定

- `header.php` … `.header`（ロゴ・グローバルナビ・電話番号）
- `footer.php` … `.footer` ＋ スマホ固定CTA
- `front-page.php` … 各セクションを `get_template_part()` で読み込む
- `template-parts/section-*.php` … HTML内のコメントに記した単位で分割
- 店舗基本情報（住所・電話・営業時間）とお品書きは、更新頻度が高いので管理画面から編集できるようにする（テーマオプションまたはカスタム投稿1種類程度に留め、小規模店舗に不要な仕組みは作らない）
