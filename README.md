# ハッピーペイントホーム（白井工業）ホームページ

大阪市東淀川区の雨漏り修理専門店「ハッピーペイントホーム（白井工業）」のホームページです。

**本番で使うのは WordPress テーマ**です。見た目・文言は静的 HTML 版と同一で、施工事例・電話番号・LINE などは管理画面から直せるようにしてあります。

- なぜこのデザインになったのか → [`docs/design-notes.md`](docs/design-notes.md)
- 掲載情報の出典と要確認リスト → [`docs/content-source.md`](docs/content-source.md)

---

## 1. 本番への入れ方（WordPress）

エックスサーバー・さくらインターネットなど、WordPress が入るレンタルサーバーであればこの手順で公開できます。追加プラグインは不要です。

1. サーバーのコントロールパネルから WordPress をインストールする（まだの場合）
2. このリポジトリの `wp-content/themes/happypainthome` フォルダを zip に固める

```bash
cd wp-content/themes
zip -r happypainthome.zip happypainthome -x "*.DS_Store"
```

3. WordPress 管理画面 → **外観 → テーマ → 新規追加 → テーマのアップロード** で `happypainthome.zip` をアップロードし、有効化する
4. **設定 → パーマリンク** を「投稿名」にして保存する（テーマ有効化時にも設定しますが、サーバーによっては再保存が必要です）
5. トップページと `/works/`（施工事例 35件）が表示されれば完了です

テーマを有効化した時点で、公式サイト掲載の施工事例 35件が自動で投入されます。

管理画面のログイン URL は `https://（ドメイン）/wp-admin/` です。

## 2. 公開後の直し方

### 電話・LINE・メール・住所・実績数値

**外観 → カスタマイズ → ハッピーペイントホーム**

| セクション | 直せるもの |
| --- | --- |
| 店舗情報 | 屋号、電話、携帯、LINE URL、メール、Instagram、住所、代表名、職人歴 |
| 実績・評価（要確認項目） | 年間施工件数、平均施工単価、保証年数、Googleマップ評価・件数 |

1か所直すと、ヘッダー・ファーストビュー・お問い合わせ・会社概要・フッター・スマホ固定ボタンのすべてに反映されます。

### 施工事例を追加する

1. **施工事例 → 新規追加**
2. タイトルは「淀川区 雨漏り修理」のように「地域＋工事内容」
3. アイキャッチに施工前／施工中／施工後の写真を設定
4. 「施工事例の詳細」に地域・地域グループ・工事内容・施工費用・築年数・原因を入力
5. 公開する

初期 35件を入れ直したい場合は **施工事例 → 初期データを投入** を使います。既存を上書きするチェックは、管理画面で直した内容が戻るので通常はオフのままにしてください。

### よくある質問・本文

トップページの文章はテーマの `front-page.php` に入っています。質問の追加は、同じファイルの FAQ ブロックをコピーし、`aria-controls` と `id` を重複しない値に変更してください。あわせて `functions.php` の FAQPage 構造化データにも追記します。

## 4. 制作区分：【既存サイトなし＝新規制作】

プロジェクト内に既存の HTML / CSS / JS / 画像は存在しませんでした。
公式サイト（Jimdo）の文言・数値・写真を一次資料として扱い、店舗が自ら選んだ言葉は原文のまま引き継いでいます。
WordPress 化にあたってデザイン・文言・写真の差し替えは行っていません。変わったのは「サーバーに上げて、管理画面から直せる」ことだけです。

## 6. 実装の要点

デザインの色・書体・余白を変える場合は、テーマ内の `assets/css/style.css` 先頭にある `:root` を直してください（静的 HTML 版の同ファイルと同じトークンです）。

```css
:root {
  --navy:   #0d2b4e;   /* 主色 */
  --orange: #ef7215;   /* アクセント（CTA） */
  --paper:  #f6f4f0;   /* 背景の紙色 */
  --container: 1180px; /* コンテンツ最大幅 */
}
```

### レスポンシブ
- スマートフォン優先で設計。本文 17px / 行間 1.95（主要読者が40〜70代のため大きめ）
- 320px 〜 1920px で横スクロールが発生しないことを確認済み
- タップ領域は最小 48px、画面下部の固定CTA（電話／LINE）は 62px

### アクセシビリティ
- スキップリンク、`:focus-visible` のフォーカスリング
- ハンバーガー・FAQ は `aria-expanded` / `aria-controls` で状態を通知
- 施工事例フィルターは `aria-pressed`
- すべての画像に内容を説明する `alt`
- `prefers-reduced-motion: reduce` でアニメーションを停止

### SEO
- `title` / `meta description` / `canonical` / OGP
- 構造化データ：`RoofingContractor`（トップ）、`FAQPage`（トップ）、`BreadcrumbList`（施工事例）
- 見出しは `h1` → `h2` → `h3` の階層を厳守
- すべての `img` に `width` / `height` を指定（レイアウトシフト対策）、ファーストビュー以外は `loading="lazy"`

> 構造化データに `aggregateRating` は入れていません。公開時点の正確な評価・件数が確認できてからの追加を推奨します。

### JavaScript
`assets/js/main.js` の1ファイルのみ（外部ライブラリなし）。
JavaScript が無効でも、コンテンツはすべて読める状態を保っています
（FAQ の回答だけが開けなくなりますが、本文は HTML に存在します）。

## 7. 公開前の確認事項

**必ず [`docs/content-source.md`](docs/content-source.md) の「要確認リスト」をご確認ください。**
特に次の項目は、店舗様の確認なしに公開しないでください。

- 年間施工件数・平均施工単価（公式サイトと外部媒体で表記が異なります）
- Googleマップの評価・口コミ件数
- 雨漏り保証の適用条件
- 施工事例写真の掲載許可の範囲
- 正式なロゴデータ（現在は暫定の SVG で再現しています）
- 公開ドメイン（WordPress 側のサイトアドレスが `canonical` / OGP / 構造化データに使われます。インストール後に **設定 → 一般** で正しい URL を確認してください）
