# 薩摩自動車 提案用デモサイト

大阪市東淀川区豊里の自動車整備工場「薩摩自動車」向け、営業提案用の1ページサイトです。
HTML / CSS / JavaScript のみで、ビルドは不要です。

掲載している事実の出典と、公開前に店舗へ確認する項目は [`docs/content-source.md`](docs/content-source.md) を見てください。

## 表示

```bash
python3 -m http.server 4321
# http://localhost:4321/
```

検索に出さないため、`noindex` を入れています。正式公開時に外してください。

## 受付状況の切り替え

いまは新規の整備・修理・車検を一時停止している状態です。`index.html` の `body` は `data-intake="paused"` です。受付の見出しと本文は `#status` にあり、ファーストビュー、固定ボタン、最終案内はここへつながります。

`data-intake` は次の3つです。

| 値 | 意味 | ボタン | 受付案内 |
| --- | --- | --- | --- |
| `paused` | 新規の整備・修理・車検を停止 | 受付状況を確認する | 表示する |
| `partial` | 一部だけ相談できる。受けられる内容は断定しない | 受付状況を確認する | 一部案内に切り替える |
| `open` | 新規の相談を案内できる | 車について相談する | 隠す。遷移先は `#contact` |

`data-accepting-new="true"` は、`data-intake` が無いときの `open` として残しています。再開するときは `data-intake="open"` にし、FAQと構造化データの日付も、その時点の告知に合わせて書き換えてください。

## 写真

`assets/img/` の写真は提案用のイメージです。実在のスタッフ、設備、施工事例としては使っていません。差し替えファイル名は [`docs/images.md`](docs/images.md) です。

集合写真（4人）は使っていません。公式のお知らせでは、整備士1名と従業員1名の体制です。
