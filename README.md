# 中房家 ホームページ

大阪市東淀川区菅原の中華料理・大衆居酒屋「中房家」の公式サイト（静的HTML／WordPress移行前提）。

サイトコンセプト：**「うまいもんを、腹いっぱい。人の温かさまで味わえる、街の中房家。」**

---

## 1. ファイル構成

```
index.html                    トップページ（1ページ完結構成）
css/style.css                 スタイル。冒頭にデザイントークンを集約
js/main.js                    ドロワーメニュー／ヘッダー影／フェードイン のみ
images/placeholder-light.svg  写真差し替え用プレースホルダー（明るい背景用）
images/placeholder-dark.svg   写真差し替え用プレースホルダー（暗い背景用）
images/photos/                実店舗写真の置き場所（納品後ここに配置）
```

ローカル確認は任意の静的サーバーで。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 2. デザインの意図（なぜこのデザインなのか）

| 設計判断 | 理由 |
| --- | --- |
| 生成り（#F7F3EA）＋薄い罫のテクスチャをベース | 高級中華の黒×金ではなく「大衆感 × 清潔感」。紙の品書きの手触りを土台にした |
| 赤は暖簾・番号・CTAのみ | 画面全体を赤くせず、行動してほしい場所だけに赤を集中させる |
| ランチ＝明るい生成り／夜＝チャコール | 「昼は定食、夜は居酒屋」という中房家の二面性を、色の明度差で体感させる |
| お品書きを短冊（紙片）レイアウトに | 町中華の壁の品書きが原型。均一なカードの羅列を避け、店の実景に寄せた |
| 選ばれる理由を左右交互＋大きな番号 | 3枚並列カードのテンプレート感を避けつつ、3つの強みを強く印象づける |
| お客様の声は★評価ではなく「評価が集まっている観点」 | 架空の口コミを作らない方針のため。何が褒められている店かだけを伝える |
| スマホ下部固定CTA（電話／アクセス） | 主目的が来店・電話。予約URLが未提供のため、確認できる手段だけを置いている |

## 3. 修正しやすさのルール

- **色・フォント・余白**：`css/style.css` 冒頭の `:root` のカスタムプロパティを変更すれば全体に反映される。
- **店舗情報**：住所・電話・最寄り駅などの本文表記は「アクセス」セクションの `dl.spec` と `footer` に集約。
- **電話番号**：`index.html` 内の `tel:0669905578` と表示用テキスト `06-6990-5578` を検索して一括置換する。
  ```bash
  grep -n "0669905578\|06-6990-5578" index.html
  ```
- **写真**：すべてプレースホルダー `images/placeholder-*.svg`。実写を `images/photos/` に置き、`src` を差し替えるだけで比率・レイアウトは崩れない（`.photo` 側で `aspect-ratio` を固定済み）。`alt` は「どんな写真を入れる想定か」を書いてあるので、差し替え時に実態へ更新する。
- **セクション**：`index.html` の各セクションは `<!-- ==== 番号 セクション名（WP: template-parts/...）==== -->` で区切ってある。WordPress化の際はこの単位で `template-parts/` に分割する想定。

## 4. 写真素材の状況（未提供）

現時点で実店舗写真は未受領のため、全カットがプレースホルダーです。優先度順に必要な写真：

1. **料理＋店内＋スタッフの空気感が同時に伝わる1枚**（ファーストビュー用・最重要）
2. 外観（店名が見える正面＋周辺が分かるカット）
3. 店内全体（席の種類・広さが分かるもの）
4. スタッフ・大将（笑顔での接客・調理の自然なカット。中房家最大の差別化要素）
5. 料理単品 5〜10品（炒飯・麺・一品料理など）
6. ランチ（日替わり・定食）
7. 夜の店内、お酒、グループ利用
8. JR淡路駅からの徒歩ルート写真（駅から約522mのため、初来店の不安解消に有効）
9. ロゴデータ（現在はヘッダーの「中」マーク＋テキストで暫定表示）

他店の写真・ストック素材・生成画像を中房家の写真として使用しないこと。

## 5. 店舗への確認事項（サイト公開前に必須）

画面上では `要確認` チップで該当箇所を明示しています。

- 正式な営業時間 / 定休日（掲載媒体によって記載差があるため必ず店舗確認）
- ランチの営業時間・内容・価格
- 現在のお品書き（提供中の料理）と価格
- ドリンク・お酒のラインナップと価格
- 予約方法（電話受付の時間・条件、ネット予約の有無とURL）
- 席数・座敷・個室・宴会・貸切の対応
- 駐車場
- 支払い方法（カード・電子マネー・QR）
- テイクアウトの現在の対応状況
- 郵便番号
- 公式Instagramアカウント（確認できれば `index.html` の Instagram セクションのコメントを解除）
- 店主様からのごあいさつ文（「中房家とは」の本文を差し替え）
- 掲載可能な口コミ本文と出典（現在は評価の傾向のみ掲載）

未確認の情報は、確定するまで断定表現で書かない方針です。

## 6. WordPress化のときの想定

- `header.php` … `.header`（ロゴ・グローバルナビ・電話番号）
- `footer.php` … `.footer` ＋ スマホ固定CTA
- `front-page.php` … 各セクションを `get_template_part()` で読み込む
- `template-parts/section-*.php` … HTML内のコメントに記した単位で分割
- 店舗基本情報（住所・電話・営業時間）とお品書きは、更新頻度が高いので管理画面から編集できるようにする（テーマオプションまたはカスタム投稿1種類程度に留め、小規模店舗に不要な仕組みは作らない）
