# 薩摩自動車 提案用デモサイト

大阪市東淀川区豊里の自動車整備工場「薩摩自動車」向け、営業提案用の1ページサイトです。
HTML / CSS / JavaScript のみで、ビルドは不要です。

掲載している事実の出典と、公開前に店舗へ確認する項目は [`docs/content-source.md`](docs/content-source.md) を見てください。

## 表示

```bash
python3 -m http.server 4321
# http://localhost:4321/
```

検索に出さないため、`noindex` を入れています。正式公開時に外してください。

## 受付状況の切り替え

いまは新規の整備・修理・車検をご依頼いただけない状態です。`index.html` の `body` は `data-accepting-new="false"` です。

再開したら、次の2か所を変えます。

1. `body` の `data-accepting-new` を `true` にする  
   ボタンが「車について相談する」に変わり、受付状況の帯が隠れます。
2. `#status` と、最終案内の文章を、その時点の案内に書き換える

## 写真の差し替え

人物や店舗に見える素材は入れていません。`figure.frame` の中を、店舗から受け取った写真の `img` に差し替えてください。

優先する写真は、整備士が車を点検しているところ、お客様へ説明しているところ、店舗の外観、スタッフ、工場の中です。
