# 有限会社セイコー工芸 — 営業用デモサイト

大阪市東淀川区の看板製作・施工会社「有限会社セイコー工芸」の、ホームページリニューアル提案用デモです。
正式な公開サイトではありません。HTML / CSS / JavaScript のみで、ビルドは不要です。

掲載の根拠と、公開前に確認する項目は [`docs/content-source.md`](docs/content-source.md) にまとめています。
デザインの意図は [`docs/design-notes.md`](docs/design-notes.md) です。

## 表示

```bash
python3 -m http.server 4321
```

ブラウザで http://localhost:4321/ を開きます。

## ファイル

```
index.html              1ページ構成
assets/css/style.css    スタイル（先頭に目次）
assets/js/main.js       メニュー、デモフォーム、スクロールのフェード
assets/img/             現行公式サイトから転載した写真
docs/                   出典とデザインメモ
```

## 直し方

色・書体・余白は `assets/css/style.css` の `:root` です。

| 変えたいもの | 探す文字列 |
| --- | --- |
| 電話番号 | `0663292222` と `06-6329-2222` |
| 住所 | `菅原3丁目4-24` |
| メインコピー | `つくりたい` |
| 会社概要 | `index.html` の `#company` |

写真を差し替えるときは、同じファイル名で上書きするか、`index.html` の `src` を変えてください。`width` と `height` も実寸に合わせます。

お問い合わせフォームは送信しません。ボタンを押すと、デモである旨のメッセージが出ます。送信先が決まり次第、`assets/js/main.js` のフォーム処理を置き換えてください。

## 現行サイトから引き継いでいること

- 「お客様のニーズに応える」という考え方
- 1979年創業、1982年法人設立、2001年に2代目が継承
- 看板の企画・製作・施工と、LED、テント、塗装、内装、電気工事
- 会社概要に載っている登録・資格・連絡先
- 施工写真集の写真

指定のメインコピーは「お客様の『つくりたい』を、カタチに。」です。
