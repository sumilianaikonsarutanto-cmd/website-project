## 2. 考え方（言い換えずに残しているもの）

トップページの挨拶と、スライドに入っている文言です。

- 「常に対応出来るサインで、お客様のニーズにお答えします。」（トップのスライド）
- 時代のニーズに合った広告媒体を、その街に合ったデザインと技術で、製作から施工まで提供する
- 以前は派手な看板、最近は美術的なデザインを望むお客様が増えている
- 小さな看板から大型看板、LEDの組み上げ、あらゆるサイン
- 主力はサイン。テント、塗装、内装、電気工事もする
- 営業担当がお伺いし、詳しく説明する

メインコピー「お客様の『つくりたい』を、カタチに。」は、今回のデモのために指定された新しい表現です。既存の「ニーズに応える」を置き換えるものではなく、同じ方向の言葉として使っています。

## 4. ご依頼の流れ

現行ページ「発注から施工まで」（`hachu_seko.html`）の5段階です。

1. お問い合わせ。場所と、つくりたい看板を相談。スタッフがアドバイス
2. 打ち合わせで希望を聞き、現場調査で立地と寸法を確認
3. プラン、納期、見積りを連絡。支払い条件を確認して発注・契約
4. デザイン校正のあと、素材に合った方法で製作
5. お客様の最終確認のうえ、完成・納品

デモの見出しは指定どおり「お問い合わせ / ヒアリング・現地確認 / ご提案・お見積り / 製作 / 施工」です。5番目の現行文言は「完成・納品」なので、施工の範囲は正式制作時に確認する注記を入れています。
