# 設計メモ ― 武住設

## このサイトで伝えること

住まいの「困った」を、水まわり・ガス・電気の区別がつかない段階から相談できる、東淀川区の町の設備店。

価格や施工件数では競わない。口コミにある「まだ大丈夫です。今替えると勿体無いですよ。」を、サイトの中心に置いている。

## 見た目

「町の設備屋 × 現代的な安心感」。

- 白とオフホワイトを基調にし、濃紺は見出しとフッター、オレンジは電話ボタンだけに使う
- 角丸はボタンの 8px だけ。カードの影やグラデーションは使わない
- 見出しはゴシック。お客様の言葉だけ明朝体
- 写真は公式サイトの実物を、引き伸ばさず印刷物のサイズで置く。実在しない写真は置いていない
- 動きはほぼなし。メニューと FAQ は `details` で、JavaScript がなくても読める

## 構成

ファーストビューで「何の店か・どこか・相談してよいか」を出し、その直後に登録・認定を一行で見せる。続けて、交換を急がせない姿勢、選ばれる理由、困りごと、サービス、人、施工事例、口コミ、流れ、FAQ、店舗、電話、の順。

スマホでは画面下に電話ボタンを固定している。問い合わせフォームは公式サイトに確認できなかったため、電話とメールだけにしている。
