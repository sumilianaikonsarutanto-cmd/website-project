# 設計メモ ― なぜこのデザインなのか

ハッピーペイントホーム（白井工業）／大阪の雨漏り修理専門店

---

## 0. 制作区分

| 判定 | 内容 |
| --- | --- |
| **既存サイトなし（新規制作）** | プロジェクト内に HTML / CSS / JS / 画像などの既存ファイルは存在しませんでした（`README.md` のみ）。 |

ただし、公式サイト（Jimdo）は稼働中のため、**そこに掲載されている文言・数値・写真を一次資料として扱い、事実はすべてそこから取得**しています。
「既存サイトの良い部分を残す」というルールは、**デザインではなく “掲載されている事実と店舗の言葉づかい” を残す**という形で適用しました。

### 既存 Jimdo サイトから引き継いだもの

- 店舗が自ら選んだ言葉（「雨漏りは塗装では止まりません」「自分の家ならどう直すか」「お客様へのお約束」4項目 など）は、**原文のまま**使用
- 施工事例の地域・費用・築年数・原因の記載
- ブランドカラー（ロゴの**オレンジ**／LINE 案内バナーの**濃紺**）
- 代表の顔写真、現場写真（すべて既存サイト掲載のもの）

### 作り直したもの

- 情報設計（Jimdo では費用の羅列が延々と続き、「何が違う会社なのか」が3秒で伝わらなかった）
- 導線（相談までの心理ステップを踏ませる構成へ）
- レスポンシブ / アクセシビリティ / SEO 構造

## 1. この店舗の本質（分析からの結論）

> お客様が買っているのは「修理」ではなく、**「騙されずに済む安心感」**。

屋根は施主から見えない。だから「本当にその工事が必要か」を判断できない。
この店舗の価値は、**必要のない工事を提案しないこと**にある。

したがってサイトの役割は「かっこよく見せること」ではなく、
**「この人なら、嘘をつかなそうだ」と数秒で感じてもらうこと**。

## 2. デザイン方針：「広告」ではなく「現場の記録」に見せる

一般的なリフォーム会社サイトは、
**大きな家の写真＋グラデーション＋「地域No.1」＋均一なカードの羅列**になりがちです。
それは「営業会社の広告」に見え、今回のターゲット（高額工事を警戒している50〜70代）の警戒心を強めます。

そこで本サイトは逆方向に振りました。

| やったこと | なぜ |
| --- | --- |
| **装飾を削り、余白と文字で語る** | 派手さ＝営業色。削るほど「職人が書いた文章」に見える |
| **キーメッセージだけ明朝体**（Zen Old Mincho） | ゴシック一色の広告調を避け、「手紙・言葉」の温度を出す |
| **オレンジは CTA と罫線のみ**に限定 | 色数を絞るほど信頼される。オレンジを撒くと安売りチラシになる |
| **数値は条件付きコンデンス書体**（Barlow Semi Condensed） | 実績・費用を「記録・データ」として読ませる |
| **写真は加工しない** | 既存の施工写真は文字が焼き込まれた“現場そのもの”。あえて整えず、記録性を活かす |
| **アニメーションは fade-up 1種のみ** | 動きが多いサイトは「作り込まれた広告」に見える |

### カラー

| 役割 | 値 | 根拠 |
| --- | --- | --- |
| ベース | `#ffffff` / `#f6f4f0`（わずかに温かみのある紙色） | 清潔さ＋冷たくなりすぎない |
| 主色 | 濃紺 `#0d2b4e` | 既存 LINE 案内バナーの帯色。雨＝水／信頼／建築 |
| アクセント | オレンジ `#ef7215` | 既存ロゴの屋根マークの色。問い合わせ＝温かさ |

濃紺は「断定する場所」（お約束・主張・フッター）にだけ全面使用し、
本文エリアは白と紙色で軽く保つことで、**重い＝old / 軽い＝信用できない**の両方を避けています。

### タイポグラフィ（50〜70代が主読者）

- 本文 `17px`（SP）/ `17.5px`（PC）、行間 `1.95`
- 見出しは最大 `clamp(28px, 6vw, 46px)` で、**詰め込まず改行位置を手で制御**
- タップ領域は最小 `48px`、固定 CTA は `60px`

## 3. セクション設計と役割

| # | セクション | 役割 | 意図的な作り分け |
| --- | --- | --- | --- |
| 1 | ファーストビュー | 「ここなら相談できそう」 | 左に言葉・右に現場写真の**非対称分割**。家の完成写真ではなく“屋根に登って作業している写真”を使い、営業会社との差を一目で出す |
| 2 | 実績バー | 判断材料を即提示 | カードにせず**横一列の帯**。数字を読ませることが目的で、装飾は不要 |
| 3 | その工事、本当に必要ですか？ | 他社との違いの核心 | 全面濃紺＋明朝の問いかけ。**お約束4項目はカードではなく罫線付きの番号リスト**（＝契約書・約款の見え方にして重みを出す） |
| 4 | 選ばれる理由 | 信頼形成 | 3枚並列カードを**禁止**し、写真と文章の**左右交互の大きな行**に。1つずつ読ませる |
| 5 | 修理の流れ | 不安の除去 | 「立ち合い不要 → 1時間で原因報告 → 当日中に費用提示」という**この店舗固有の速さ**を軸に5ステップ |
| 6 | 現場レポート | ケーススタディ化 | 既存サイトに1件だけあった工程写真（西淀川区・築65年）を**1件深掘り**。分析で指摘された「ケーススタディ化」の実装 |
| 7 | 施工事例 | 技術力・価格感 | ここだけは**均一グリッドが正解**。地域・費用を横並び比較させるため。写真自体に Before/After が焼き込まれているので余計な装飾は載せない |
| 8 | 料金の目安 | 高額請求への不安を減らす | 金額の羅列ではなく**実績の分布バー**（70%/20%/10%）。「自分はどのくらいか」を推測させる |
| 9 | お客様の評価 | 第三者の信頼 | **口コミ本文は未確認のため掲載していない**（後述） |
| 10 | 職人紹介 | 「誰が来るの？」の解消 | 顔写真＋店舗自身の言葉。肩書きや受賞歴は作らない |
| 11 | よくある質問 | 問い合わせ前の疑問解消 | 全問、公式サイト記載の事実のみで構成 |
| 12 | 対応エリア | 自分の地域か確認 | 施工事例から**実際に実績のある地域名**を抽出して掲載 |
| 13 | お問い合わせ | 行動 | 電話／LINE／メールを並列。PC 向けに LINE の QR を掲載 |
| 14 | 会社概要 | 最終的な安心材料 | 未確認項目は掲載しない |

## 4. CTA 設計

**CTA を増やしすぎない**方針です。心理の節目にだけ置いています。

1. ファーストビュー（まだ何もわからない段階 → 「無料で相談する」）
2. 「その工事、本当に必要ですか？」の直後（共感が生まれた瞬間）
3. 施工事例の直後（「似た症状だ」と思った瞬間）
4. 最下部（結論を出した段階）
5. スマホ固定バー（電話／LINE の2つのみ）

中盤の CTA 文言は「見積もり依頼」ではなく
**「これって修理が必要？だけでもご相談ください」**とし、
問い合わせのハードルを下げています。これは分析の中心メッセージと一致します。

## 5. 作っていないもの（意図的な不採用）

- **ガラスモーフィズム／大きな角丸／グラデーション背景** … 営業色が出るため
- **「創業○年」「お客様満足度○%」などの数字** … 資料で確認できないため
- **スタッフ紹介の複数名掲載** … 確認できるのは代表のみ
- **口コミ本文** … 掲載許可・原文が未確認。枠だけ用意し、差し替え可能にしている
- **ストック素材の職人写真・AI生成の住宅写真** … この店舗ではリアルな施工写真のほうが価値が高い
