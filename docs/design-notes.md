- 他店購入車も見る。外車、部品が手に入りにくい旧車、無茶なカスタムなどは断ることがある。
- 電話 06-6325-9995。問い合わせは公式フォーム。写真添付の条件が書いてある。
- 定休日の表記がページで一致しない（出典メモ参照）。

### このデモでの提案

- 店を「販売と修理の一覧」ではなく、直す技術とつくる技術の工房として見せる。
- ファーストビューは、加工部品の実写と「まずは相談」を並べ、電話と公式フォームへつなぐ。
- 作業はカードを並べず、前後の写真を誌面のように大きく置く。
- 受けられない仕事と、ページ間で割れている定休日は、隠さず上の方に出す。
- 相談手順のうち、店舗が公開していない部分は「デモ用の仮案」と分ける。

以前のファイルは別店舗（雨漏り修理）の静的サイトだった。技術は HTML / CSS / JS のままにした。中身と見た目は、モトショップズームの提案として作り直している。

| 役割 | 値 |

ヒーローは画面いっぱいの黒、本文は紙色、仕事と相談は再び黒。同じ角丸カードは使っていない。
