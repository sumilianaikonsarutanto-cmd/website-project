# デザインメモ

薩摩自動車の提案デモ。コンセプトは「車のことが分からなくても、安心して相談できる地域の整備工場」。

安い・速い・台数、では隣の車検店と並ばない。口コミで繰り返し出るのは、親切、説明、預けたときの安心。ファーストビューの見出しは「車のことなら、まず薩摩自動車へ。」、中盤の見出しは「ちゃんと見て、ちゃんと伝える。」にした。

見た目は、白ヘッダー、ネイビーの文字、青いボタン、写真のヒーローがある車屋サイトを基準にしている。文章はこれまでの薩摩自動車の内容のまま。写真は提案用のイメージで、実在のスタッフや施工事例としては扱わない。4人並びの集合写真は「整備士1名＋従業員1名」と食い違うため使っていない。差し替え一覧は `docs/images.md`。

新規の整備・修理・車検は 2026年9月16日の告知どおり停止中。「今すぐ予約」「新規歓迎」は置いていない。受付の文章とボタンは、`body` の `data-intake`（`paused` / `partial` / `open`）で切り替える。
