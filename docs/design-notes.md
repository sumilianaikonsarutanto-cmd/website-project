# 設計メモ

有限会社セイコー工芸 / 営業用デモ

## このページの役割

現行サイトの考え方を、別の理念に置き換えていません。
「お客様のニーズに応える」を、初めてサイトを開いた人にも伝わる形へ組み直しています。

見ている人に辿ってほしい順は次のとおりです。

1. 看板の会社だと分かる
2. いろいろな看板に対応している
3. 看板以外の工事も相談できる
4. 1979年から続いている
5. 実在の会社だと分かる
6. 電話か問い合わせをする

## 見た目

印刷物の会社案内に近い組み方です。

- 地の色は薄い生成り、文字は墨に近い色。金属の看板を思わせる鈍い金は、年号と罫線だけに使っています
- 角を丸めていない。影とグラデーションも使っていません
- 見出しは明朝、本文はゴシック。英語の大見出しは置いていません。ナビの英語は指定どおりです
- 写真はカードの中に収めず、説明文と横並びにしています
- 動きは、最初の画面のフェードと、スクロールで現れるフェードだけです

## 写真

施工事例以降は、現行サイトの施工写真だけを使っています。解像度は元データのままなので、画面いっぱいに引き伸ばしていません。スマートフォンでは横幅いっぱい、パソコンでは本文より写真が広くなる比率にしています。

ファーストビューは、提案用に生成した壁面サインのイメージです。施工実績の写真は使っていません。作業場の写真は「製作から施工まで」の説明にだけ置いています。

## 書いていないこと

施工件数、満足度、地域No.1、受賞、口コミ、架空の顧客名、架空のスタッフは入れていません。
塗装と内装は、現行サイトが営業種目として挙げている範囲の一文にとどめています。
