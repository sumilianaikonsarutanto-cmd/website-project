## 1. ブランドの本質

> 売っているのは「ホームページ」ではなく、**価値が伝わり、問い合わせにつながる見せ方**。

ターゲットは、現場の技術はあるがWebで魅力を伝えきれていない中小企業（建設・設備・自動車・地域店舗）。
実績数字で押し切れない段階でも、**提案の具体性・情報設計・デザイン完成度**で信頼を取る。

## 2. アートディレクション

世界水準のデジタルスタジオ × 日本のエディトリアル。

| 原則 | 実装 |
| --- | --- |
| 大胆なタイポグラフィ | Shippori Mincho の巨大見出し + 意図的改行 |
| 非対称レイアウト | FVは左コピー / 右サイド情報。カードの均一並べを避ける |
| 緻密なグリッド | 番号付きリスト・2カラムの比率をセクションごとに設計 |
| 写真 | 現場・職人・店舗の雰囲気（ストック）。ノートPCの制作会社あるあるは不使用 |
| 余白とコントラスト | ダーク `#101110` とライト `#F0EEE6` を交互に |
| アクセント | ライム `#C8F169` は CTA・番号・キーワードのみ |
| 動き | fade/rise、軽いズーム、clip。過度なパララックスなし |

英語コピー **Connect Value. Design Impact.** は FV 端・Philosophy・Footer に限定。

## 3. セクション役割

| # | セクション | 役割 |
| --- | --- | --- |
| 01 | Hero | 何をするか / 誰向けか / 何を相談できるかを数秒で |
| 02 | Problem | Webで伝わらない課題を具体化 |

| 09 | FAQ | 未確定事項を断定しない回答 |

| 11 | Footer | ナビ・事業内容・コピーライト |

## 4. 意図的にやらなかったこと

- 確認できない売上改善率・顧客数・推薦コメント
- 実在企業名の無断掲載
- 仮の電話番号・メール・LINE
- カードだらけのテンプレート構成
- 紫グラデーション / 汎用AIランディングの見た目

---

## 5. 動き

- ページ表示時のヒーロー文字 rise-in
- スクロール reveal（IntersectionObserver・1回のみ）
- 画像の緩やかなズーム / clip
- CTA ホバー
- `prefers-reduced-motion: reduce` でアニメ停止
