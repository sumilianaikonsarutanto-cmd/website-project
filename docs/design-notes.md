# デザインメモ

薩摩自動車の提案デモ。コンセプトは「車のことが分からなくても、安心して相談できる地域の整備工場」。

安い・速い・台数、では隣の車検店と並ばない。口コミで繰り返し出るのは、親切、説明、預けたときの安心。ファーストビューの見出しは「車のことなら、まず薩摩自動車へ。」、中盤の見出しは「ちゃんと見て、ちゃんと伝える。」にした。

色はオフホワイト `#F7F5F0`、墨 `#1E2933`、赤 `#B32025` をボタンと小さい目印だけに使っている。レーシングカーのような黒赤にはしていない。

写真は受け取っていない。整備士の顔に見える素材は置かず、点検・店舗・説明の三つを線画の枠で示し、キャプションに入れる写真を書いた。

新規の整備・修理・車検は 2026年9月16日の告知どおり停止中。「今すぐ予約」「新規歓迎」は置いていない。受付の文章とボタンは、`data-accepting-new` で後から差し替えられる。
