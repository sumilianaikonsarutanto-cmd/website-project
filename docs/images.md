# 写真の扱い

このデモで使っている写真は、提案用のイメージです。薩摩自動車のスタッフ、設備、施工事例を証明するものとしては使っていません。公開前に、同じファイル名の実写へ差し替えてください。

看板や作業着の文字が画像の中に入っていても、店舗の掲示や資格の証明にはしていません。

使っていない素材: 4人並びの集合写真。公式のお知らせの「整備士1名＋従業員1名」と食い違うため、ファイル化していません。
