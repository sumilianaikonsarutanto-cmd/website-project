## 1. この店舗の本質（分析からの結論）

> お客様が買っているのは「回収」ではなく、**「知らない人を家に入れても大丈夫だ、という安心」**。

不用品回収の検索ユーザーは、ほぼ全員が次の3つを同時に抱えています。

1. 早く片付けたい（急いでいる）
2. いくらかかるか分からない（不透明さへの不安）
3. 業者が怖い／強引ではないか（人への不安）

競合（オーケー大阪、関西プロスタッフ 等）は 1 と 2 に対して「即日」「追加料金なし」「低価格」で答えています。
一方、ステルンのクチコミで繰り返し評価されているのは **3 に対する答え＝丁寧さ・親切さ・感じの良さ** です。

したがってこのサイトの役割は、「安い・早い」を叫ぶことではなく、
**「この会社なら、家に呼んでも大丈夫そうだ」と数十秒で感じてもらうこと**に置きました。

## 2. デザイン方針：「チラシ」ではなく「片付いた部屋」

不用品回収サイトは、赤・黄の激安訴求、価格表の羅列、ゴミ山の写真になりがちです。
それは「安さで戦う会社」の見た目であり、ステルンの強み（丁寧・安心）とは逆방向です。

そこで本サイトは、**画面そのものを「片付いた部屋」に見立てました**。

| やったこと | なぜ |
| --- | --- |
| **余白を広く取り、要素を整列させる** | 散らかっていない画面 ＝ 散らかさない会社。サービスの価値をレイアウトで語る |
| **色を3色に絞る（ネイビー／グリーン／黄）** | 色数が増えるほど「安売りチラシ」に近づく。黄は星マークと CTA のみに限定 |
| **装飾モチーフは「星（スパークル）」1種類のみ** | 店名の Stern（独語で星）に由来。サービス項目のマーカー、ロゴ、FV のラベルに共通で使い、装飾を増やさずブランドの一貫性を作る |
| **グラデーション・ガラスモーフィズム・過度な角丸を使わない** | 意味のない装飾は「テンプレート感」に直結する |
| **アニメーションは fade-up 1種のみ** | このサイトで優先するのは動きではなく安心感 |
| **同じ形のカードを並べない**（後述） | 均一なカードの羅列は AI 生成サイトの典型 |

### カラー（設計書の指定値を採用）

| 役割 | 値 | 使いどころ |
| --- | --- | --- |
| 主色 | Dark Navy `#17232f` | 見出し・「お客様からの評価」の面・フッター。信頼と落ち着き |
| 副色 | Green `#3c8067` | CTA・ラベル・アイコン。リサイクルと安心 |
| 差し色 | Warm Yellow `#e9b949` | 星マーク、ページ後半の CTA のみ。人の温かさ |
| 背景 | `#f7f8f6` / `#ffffff` | セクションの交互配置 |
| 淡グリーン | `#eef3f0` | FV 背景と料金セクションの囲み |

ネイビーは「断定する場所」だけに全面使用し、本文エリアは白と紙色で軽く保っています。
**重すぎる＝威圧的、軽すぎる＝安っぽい**の両方を避けるためです。

### タイポグラフィ

- 日本語 Noto Sans JP、英数字 Inter（設計書の指定）
- 本文 16px / 行間 1.9。主要ターゲットが30〜60代のため、小さくしない
- 数字（電話番号・評価・STEP・理由の番号）はすべて Inter。**「読む文字」と「見る数字」を書体で分離**している
- 見出しは `clamp()` で可変。詰め込まず、改行位置を手で制御

## 3. セクション設計と、レイアウトの作り分け

セクションの順番は設計書どおり（変更なし）。ただし**すべてを同じカードUIにしない**ことを徹底しました。

| # | セクション | 役割 | レイアウトの意図 |
| --- | --- | --- | --- |
| 01 | ファーストビュー | 何の会社か・自分向きかを即理解 | 左にコピー、右に写真の非対称分割。背景は淡グリーンをわずかに傾けて分割し、直下に**事実だけを並べた帯**（評価・所在地・受付時間）を置く。誇張ではなく事実で信頼を作る |
| 02 | こんなお悩み | 自分ごと化 | カードではなく**チェックリスト**。ユーザーが自分の状況に印を付ける感覚にする。5項目めは全幅にして視線を締める |
| 03 | 選ばれる理由 | なぜステルンか | 箱で囲まず、**縦罫線で区切った3本の柱**。各項目の最後に「クチコミでの評価：〜」を黄色の罫線付きで添え、**自社の主張を第三者評価で裏づける**構造にした（この業種では主張だけでは信用されない） |
| 04 | 対応サービス | 自分の不用品も頼めるか | 左に写真（PC ではスクロール追従）、右に**罫線区切りのリスト**。6枚の均一カードにすると内容の薄さが目立つうえ、テンプレート感が出る |
| 05 | 料金・見積もり | 最大の不安の解消 | 料金表が未確認のため、金額ではなく**「見積もりが決まる3つの要素（品目・量・搬出条件）」**を提示。「分からない」ではなく「こう決まる」に変換することで、不透明感を減らす |
| 06 | 作業事例 | 実在性の証明 | Before / After の2枚組。写真が最重要なので文字は最小限。**現在は写真未支給のため仮枠**（捏造しない） |
| 07 | お客様からの評価 | 第三者からの信頼 | ここだけ**ネイビーの全面**にして、ページ内で最も目立たせる。★5.0 を大きく置き、評価傾向はタグで。**クチコミ本文は転載していない** |
| 08 | ご利用の流れ | 依頼のハードルを下げる | 4ステップ。PC では横並び＋つなぎ線、SP では縦のタイムライン |
| 09 | FAQ | 最後の不安を潰す | アコーディオン。回答はすべて**断定を避けた表現**（条件が未確認のため） |
| 10 | 最終CTA・お問い合わせ | 行動 | 電話／LINE／フォームを並列。フォームは**5項目のみ**（項目が増えるほど問い合わせは減る） |
| 11 | アクセス | 会社としての実在性 | 情報は定義リスト、地図は控えめな高さ |

## 4. CTA 設計

CTA は**心理の節目にだけ**置いています（圧迫感を出さないため、セクションごとには置きません）。

1. ファーストビュー … 「無料見積もりを依頼する」／「電話で相談する」
2. 選ばれる理由の直後 … 「相談してみる」（信頼が生まれた瞬間）
3. 対応サービス内 … 「回収できるか相談する」（自分の物が対象か気になった瞬間）
4. 料金セクション … 「料金について相談する」（最大の不安の直後）
5. お客様の評価の直後 … 「まずは相談する」
6. ご利用の流れの直後 … 「まずは相談してみる」
7. 最終セクション … 電話／LINE／フォーム
8. スマホ固定バー … 「電話で相談」「無料見積もり」の2つのみ

文言は意図的に**「依頼」ではなく「相談」**に寄せています。
「まだ頼むと決めていない人」が大半で、"依頼" と書くと押しが強くなるためです。

## 5. スマートフォン設計

- 固定 CTA（電話／無料見積もり）を画面下部に常設。`body` に `padding-bottom` を確保し、コンテンツと重ならないようにしている
- ボタン高さ 52px 以上、タップ領域 48px 以上
- フォームの入力欄は 16px（iOS で自動ズームしないサイズ）
- 320px 幅で横スクロールが発生しないことを確認
- FV は「コピー → 写真」の順。**設計書では SP で写真を先頭に置く案でしたが、現時点では写真が未支給のため、仮枠が最初に来ないようコピーを先頭にしています。**
  実写真の支給後に写真を先頭へ回す場合は、`style.css` の `.hero__visual` に `order: -1`（`@media (max-width: 959px)` 内）を1行追加するだけで切り替わります

## 6. 作っていないもの（意図的な不採用）

- **料金表** … 確定した料金情報が未提供。推測の金額は掲載しない
- **「最短即日」「追加料金なし」** … 資料に公式サイトでの案内として記載があったが、現在の適用条件が未確認のため使用していない
- **スタッフ紹介セクション** … 写真・氏名が未支給。この業種では最も効果が高いため、**支給後の追加を強く推奨**
- **作業事例の中身** … 実在の事例情報が未確認。枠のみ用意
- **クチコミ本文** … 権利・掲載条件が未確認。評価傾向の要約のみ
- **自動スライダー／パララックス／派手なローディング** … 表示速度と操作性を優先

詳細は [`content-source.md`](./content-source.md) の要確認リストを参照してください。
