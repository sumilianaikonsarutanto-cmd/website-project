大阪市東淀川区の不用品回収・リサイクル回収「ステルン」のホームページです。
HTML / CSS / JavaScript のみで構成しています（ビルド不要）。

---

```

├── index.html                トップページ（1ページ完結）
├── assets/
│   ├── css/style.css         全スタイル（先頭に目次あり）
│   ├── js/main.js            共通スクリプト（約100行・外部ライブラリなし）
│   └── img/
│       ├── favicon.svg       暫定シンボル（正式ロゴ支給後に差し替え）
│       └── photo/            デモ画像（実写真ではありません）
└── docs/
    ├── design-notes.md       デザイン意図
    └── content-source.md     出典一覧 / 要確認リスト
```

### 表示方法

そのままブラウザで `index.html` を開けます。ローカルサーバーで確認する場合：

```bash
cd stern
python3 -m http.server 4321
# → http://localhost:4321/
```

### ZIP化（納品・プレビュー用）

**ブラウザで見るだけなら** `stern` フォルダ一式をZIPにしてください。

**WordPressにテーマとして入れる場合は、このフォルダではなく**
`STERN_wordpress_theme.zip`（`stern-wordpress/stern`）を使ってください。
HTML版をテーマとして上げると「style.css がありません」とエラーになります。

**ZIPにするのは `stern` フォルダ一式だけです。**  
リポジトリ直下の `index.html` / `works.html` / `assets/` / `docs/` は別店舗のサイトなので、含めないでください。

```
stern/          ← このフォルダを丸ごとZIP
├── index.html
├── assets/
└── docs/
```

解凍後、`stern/index.html` をブラウザで開けば表示されます。

## 3. 修正のしかた（変更箇所 早見表）

### 3-1. 色・書体・余白を変える

`assets/css/style.css` 冒頭の `:root` にデザイントークンを集約しています。ここだけで全体のトーンが変わります。

```css
:root {
  --navy:   #17232f;   /* 主色 */
  --green:  #3c8067;   /* CTA・アクセント */
  --accent: #e9b949;   /* 差し色（星マーク・強調CTA） */
  --paper:  #f7f8f6;   /* 背景 */
  --container: 1140px; /* コンテンツ最大幅 */
}
```

正式なブランドカラーのご指定があれば、この値を差し替えるだけで反映されます。

### 3-2. 店舗情報を変更する

静的 HTML のため、該当箇所を置換してください（出現箇所は少数です）。

| 変更したいもの | 検索する文字列 | 出現箇所 |
| --- | --- | --- |
| 電話番号 | `05031841212`（リンク）／`050-3184-1212`（表示） | ヘッダー・FV・お問い合わせ・会社情報・フッター・固定CTA |
| 住所 | `北江口4丁目2-8` | 会社情報・フッター・構造化データ |
| 郵便番号 | `533-0002` | 会社情報・フッター・構造化データ |
| 営業時間 | `9:00〜18:00` | ヘッダー・FV・お問い合わせ・会社情報・フッター |
| 事業者名 | `ステルン` | 全体 |
| Google評価 | `5.0` / `13件` | FV・お客様からの評価 |

> 電話番号は `href="tel:..."` と表示テキストの**2か所**がセットです。両方を変更してください。

### 3-3. 写真を差し替える

現在入っているのは**レイアウト確認用のデモ画像**です（ステルンの実写真ではありません）。
画像は `assets/img/photo/` にあり、各写真には「デモ画像」のラベルが付いています。

店舗様の写真に差し替える手順：

1. 画像を `assets/img/photo/` に上書き（推奨：WebP、なければ JPEG）
2. `index.html` の該当する `<img>` の `src` / `alt` / `width` / `height` を更新
3. 実写真になったら、`<figcaption class="photo__badge">デモ画像</figcaption>` を削除

- `width` / `height` は必ず指定してください（表示ズレ＝CLS の防止）
- ファーストビュー以外の画像には `loading="lazy"` を付けてください
- 必要な写真の一覧は [`docs/content-source.md`](docs/content-source.md) の「C. 写真・素材」を参照

### 3-4. よくあるご質問を追加する

`index.html` の `.faq` 内の `.faq__item` をコピーし、`aria-controls` と対応する `id`（`faq-a7` など）を
**重複しない値**に変更してください。あわせて `<head>` の FAQPage 構造化データにも同じ内容を追記します。

### 3-5. 作業事例を追加する

`.cases` 内の `<article class="case">` をコピーし、写真を差し替えて内容を記載してください。
**事例の内容は、店舗様が確認できたものだけ**を記載してください（地域・品目・作業内容など）。

## 4. 実装の要点

### レスポンシブ
- スマートフォン優先。320px〜1920px で横スクロールが発生しないことを確認済み
- タップ領域は最小 48px、ボタン高さ 52px 以上、画面下部の固定CTAは 52px
- フォーム入力欄は 16px（iOS の自動ズーム防止）

### アクセシビリティ
- スキップリンク、`:focus-visible` のフォーカスリング
- ハンバーガーと FAQ は `aria-expanded` / `aria-controls` で状態を通知
- 仮の写真枠は `role="img"` + `aria-label` で内容を通知
- `prefers-reduced-motion: reduce` でアニメーションを停止
- JavaScript が無効でも全文が読める（`.no-js` で FAQ を開いた状態にする）

### SEO
- `title` / `meta description` / OGP（URL 系はドメイン確定後に設定）
- 構造化データ：`LocalBusiness`（事実のみ）、`FAQPage`
- 見出しは `h1` → `h2` → `h3` の階層を厳守。`h1` はファーストビューに1つだけ
- 評価（`aggregateRating`）は**意図的に入れていません**。公開時点の正確な値を確認してからの追加を推奨します

### JavaScript
`assets/js/main.js` の1ファイルのみ（外部ライブラリなし）。ドロワー／FAQ／フェードイン／年号の4機能だけです。

## 5. WordPress 化について

ご指示をいただき次第、現在のデザイン・レイアウト・機能を維持したまま下記構成へ変換できるよう、
HTML をセクション単位のコメントで区切ってあります。

| 変換先 | 対応する現在の箇所 |
| --- | --- |
| `header.php` | `<head>` 〜 `</header>`（ドロワー含む） |
| `footer.php` | `<footer>` 〜 `</body>`（固定CTA含む） |
| `front-page.php` | `index.html` の `<main>` 内 |
| `page.php` / `404.php` | 共通レイアウトを流用 |
| `assets/` | そのまま `assets/` へ配置 |

管理画面から更新することになる情報：

- 電話番号・住所・営業時間・LINE URL → テーマオプション（1か所で管理し全テンプレートから参照）
- 作業事例 → カスタム投稿タイプ（写真 Before / After ＋ 内容）
- よくあるご質問 → カスタム投稿タイプ、または ACF の繰り返しフィールド
- お問い合わせフォーム → Contact Form 7 等のショートコードに置き換え（現在の `<form>` と同じ5項目）

小規模な店舗サイトのため、ページビルダーや過剰なプラグイン構成は想定していません。
