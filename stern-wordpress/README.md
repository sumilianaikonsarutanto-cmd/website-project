# ステルン WordPress テーマ

WordPress にアップロードして使うファイルです。

**インストールするZIPは `STERN_wordpress_theme.zip` です。**  
HTML版（`STERN_homepage.zip` / `stern` フォルダの index.html）をテーマとして上げると、「style.css スタイルシートがありません」というエラーになります。

## 入れ方

1. WordPress管理画面 → **外観 → テーマ → 新規追加 → テーマのアップロード**
2. `STERN_wordpress_theme.zip` を選ぶ
3. **今すぐインストール → 有効化**

トップページは `front-page.php` が自動で使われます。

## 管理画面から変えるもの

外観 → カスタマイズ → **ステルン 店舗情報**

- 電話番号
- 営業時間
- 公式LINEのURL（空欄なら「準備中」表示）

お問い合わせフォームの送信先は、設定 → 一般 の管理者メールアドレスです。
