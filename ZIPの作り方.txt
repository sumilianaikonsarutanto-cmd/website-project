ツナグWEB製作
ファイルの保存と ZIP の作り方
（ホームページの中身は変えません）


■ いちばん大事なこと

WordPress に入れるのは、このフォルダです。

  tsunagu-web

このフォルダの中に、ホームページ一式（文章・写真・デザイン）が入っています。
ZIP にするときは、「tsunagu-web フォルダごと」まとめます。
中のファイルだけをバラバラに選ばないでください。

リポジトリ直下の tsunagu-web.zip は、すでに正しい形で作ってあります。
そのまま WordPress にアップロードできます。


■ パソコンに保存する

1. tsunagu-web フォルダ（または tsunagu-web.zip）を、わかりやすい場所にコピーする
2. コピーできたら、それが原本です。消さないでください


■ Windows で ZIP にする（自分で作り直す場合）

1. tsunagu-web フォルダを、マウスの右ボタンでクリックする
2. 「圧縮」または「送る」→「圧縮（zip 形式）フォルダー」を選ぶ
3. 「tsunagu-web.zip」ができる
4. できた ZIP をダブルクリックして、中に
     tsunagu-web  →  style.css
   が見えれば成功です


■ WordPress に入れる

1. WordPress の管理画面を開く
2. 左の「外観」→「テーマ」
3. 「新規追加」→「テーマのアップロード」
4. tsunagu-web.zip を選んで「今すぐインストール」
5. 「有効化」を押す
6. 「設定」→「表示設定」で「ホームページの表示」を「最新の投稿」のままでも、
   固定ページをトップにする場合は「固定ページ」を選び、フロントに使うページを指定
   （本テーマは front-page.php があるため、通常はトップに自動で公式デザインが出ます）
7. 「設定」→「パーマリンク」で「投稿名」を選んで保存する（推奨）
8. 「外観」→「カスタマイズ」→「ツナグWEB製作」でメール／電話／LINE を設定する


■ ZIP を開いてエラーになるとき

・ZIP の中が「tsunagu-web」フォルダではなく、ファイルが直接並んでいる
・ZIP の中が「tsunagu-web / tsunagu-web」と二重になっている
・ファイルサイズ制限でアップロードできない（そのときは WordPress の
  wp-content/themes/ に、ZIP を解凍した tsunagu-web フォルダを
  そのまま置く）


■ やってはいけないこと

・ZIP の中身をバラバラにして、別のフォルダ名に変える
・style.css だけをアップロードする
・tsunagu-web のひとつ上のフォルダごと ZIP にする
