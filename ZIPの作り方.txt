ハッピーペイントホーム
ファイルの保存と ZIP の作り方
（ホームページの中身は変えません）


■ いちばん大事なこと

WordPress に入れるのは、このフォルダです。

  happypainthome

このフォルダの中に、ホームページ一式（文章・写真・デザイン）が入っています。
ZIP にするときは、「happypainthome フォルダごと」まとめます。
中のファイルだけをバラバラに選ばないでください。


■ パソコンに保存する

1. happypainthome フォルダを、わかりやすい場所（デスクトップなど）にコピーする
2. コピーできたら、それが原本です。消さないでください


■ Windows で ZIP にする

1. happypainthome フォルダを、マウスの右ボタンでクリックする
2. 「圧縮」または「送る」→「圧縮（zip 形式）フォルダー」を選ぶ
3. 「happypainthome.zip」ができる
4. できた ZIP をダブルクリックして、中に
     happypainthome  →  style.css
   が見えれば成功です


■ WordPress に入れる

1. WordPress の管理画面を開く
2. 左の「外観」→「テーマ」
3. 「新規追加」→「テーマのアップロード」
4. happypainthome.zip を選んで「今すぐインストール」
5. 「有効化」を押す
6. 「設定」→「パーマリンク」で「投稿名」を選んで保存する


■ ZIP を開いてエラーになるとき

・ZIP の中が「happypainthome」フォルダではなく、ファイルが直接並んでいる
・ZIP の中が「happypainthome / happypainthome」と二重になっている
・ファイルサイズ制限でアップロードできない（そのときは WordPress の
  wp-content/themes/ に、ZIP を解凍した happypainthome フォルダを
  そのまま置く）


■ やってはいけないこと

・ZIP の中身をバラバラにして、別のフォルダ名に変える
・style.css だけをアップロードする
・happypainthome のひとつ上のフォルダごと ZIP にする
