# 中房家オリジナルテーマ

大阪市東淀川区菅原の中華料理・大衆居酒屋「中房家」公式サイト用の WordPress テーマです。

現行の完成ホームページと**同じ見た目**のまま、管理画面から写真と文章を変更できます。

- テーマ名：中房家オリジナルテーマ
- フォルダ名：`chuboya`
- プラグインは不要です

---

## 1. インストール方法

1. WordPress 管理画面にログインします。
2. 左メニューの **外観 → テーマ** を開きます。
3. **新しいテーマを追加** を押します。
4. **テーマのアップロード** を押します。
5. `chuboya-original-theme.zip` を選び、**今すぐインストール** を押します。
6. **有効化** を押します。

これだけで、今のホームページと同じ画面が表示されます。

固定ページを作ったり、「ホームページの表示」を変えたりする必要はありません。  
テーマを有効化した時点で、トップページが中房家のホームページになります。

### ZIP の中身

ZIP を解凍すると、次のようなフォルダになります。

```
chuboya/
├── style.css
├── functions.php
├── front-page.php
├── header.php
├── footer.php
├── index.php
├── page.php
├── 404.php
├── screenshot.png
├── README.md
├── inc/
├── template-parts/
└── assets/
    ├── css/
    ├── js/
    └── images/
```

フォルダごと（`chuboya` ごと）ZIP になっていることが大切です。  
中のファイルだけを ZIP にすると、インストールできません。

## 2. 文章や写真はどこで変えるか

管理画面の左メニューに

**中房家ホームページ設定**

という項目があります。ここを開いてください。

上のタブでセクションごとに分かれています。

| タブ | ここで変えるもの |
| --- | --- |
| 基本・店舗情報 | 店名、電話、住所、営業時間、定休日、SEO |
| ファーストビュー | メインコピー、サブコピー、ボタン文言 |
| 中房家とは | 見出しと説明文 |
| 選ばれる理由 | 3つの理由の見出しと本文 |
| お品書き | 料理名、価格、説明 |
| ランチ | ランチの説明・時間・内容 |
| 夜の楽しみ方 | 夜の見出し、ドリンク |
| 利用シーン | 一人・家族・グループの文章 |
| お客様の声 | 口コミ傾向の見出しと本文 |
| よくある質問 | 質問と回答 |
| CTA | 最後の案内とスマホ下部ボタン |
| 写真14枚 | ホームページに出る写真すべて |

入力したら、一番下の **変更を保存** を押してください。

空欄にして保存すると、今の完成デザインと同じ初期の文章に戻ります。

**初期状態に戻す** を押すと、文章も写真も最初の状態に戻ります。

## 3. 写真の変更方法

1. **中房家ホームページ設定** を開きます。
2. **写真14枚** タブを開きます。
3. 変えたい写真の **画像を選ぶ** を押します。
4. メディアライブラリから写真を選ぶか、新しくアップロードします。
5. **この写真を使う** を押します。
6. 一番下の **変更を保存** を押します。

ホームページの、その写真だけが変わります。  
枠の大きさ、余白、文字の位置は変わりません。

写真をまだ用意していない箇所は、今のプレースホルダー（またはテーマ同梱の初期写真）のままなので、レイアウトは崩れません。

**初期画像に戻す** を押して保存すると、テーマに入っている今の写真に戻ります。

## 4. ファーストビュー画像の変更方法

1. **中房家ホームページ設定** を開きます。
2. **写真14枚** タブを開きます。
3. 一番上の **ファーストビュー（外観）** で **画像を選ぶ** を押します。
4. 店舗の外観写真を選んで保存します。

今入っている写真は、店舗から掲載許可を得ている中房家の外観です。  
差し替えるまでは、この写真が表示されます。

写真の説明文（代替テキスト）は **ファーストビュー** タブの「写真の代替テキスト」で変えられます。

## 5. 文章の変更方法

**中房家ホームページ設定** の各タブで、次の項目を変えられます。

- メインコピー（「うまいもんを、腹いっぱい。」）
- サブコピー
- 各セクションの見出し
- 各説明文
- CTA（ボタン）の文言

改行したい箇所は、入力欄の中で改行してください。ホームページでも同じ位置で改行されます。

見出しのデザインや色、文字サイズは変わりません。

---

## 6. メニュー（お品書き）の変更方法

1. **お品書き** タブを開きます。
2. 「料理名 1」〜「料理名 8」と、それぞれの価格を直します。
3. 価格がまだ決まっていないときは `要確認` と書いてください。今と同じ小さな文字で出ます。
4. **変更を保存** を押します。

料理の写真は **写真14枚** タブの

- お品書き：主役
- お品書き：麺料理
- お品書き：一品料理

から変えます。

---

## 7. FAQ の変更方法

1. **よくある質問** タブを開きます。
2. 質問 1〜7 の「質問」と「回答」を直します。
3. まだ確認中の内容には、下の「要確認チップを付ける」にチェックを入れます。
4. **変更を保存** を押します。

開閉する見た目はそのままです。

---

## 8. 店舗情報の変更方法

1. **基本・店舗情報** タブを開きます。
2. 次の項目を直します。
   - 電話番号
   - 住所
   - 営業時間
   - 定休日
   - 駐車場
   - お支払い方法
   - ご予約
   - 最寄り駅
3. **変更を保存** を押します。

`要確認` と入力すると、今と同じ黄色いラベルで表示されます。  
営業時間が決まったら、例：`11:00〜14:00／17:00〜23:00` のように書き換えてください。

電話番号は `06-6990-5578` のようにハイフン付きで入力します。  
ホームページの電話ボタンも、自動で同じ番号につながります。

地図は「地図検索キーワード」を変えると、埋め込み地図と「Googleマップで開く」のリンクが一緒に変わります。

## 9. 注意（デザインについて）

このテーマは、完成しているホームページの見た目を変えないことが目的です。

- 色
- 余白
- 文字サイズ
- ボタン
- セクションの順番と高さ
- 写真の枠

を、テーマの CSS で固定しています。

文章や写真を変えても、レイアウトは今のままです。  
見た目を変える必要があるときは、`assets/css/style.css` を編集する必要がありますが、通常の運用では触らないでください。

---

## 10. よくあること

**有効化したのに見た目が違う**  
ほかのテーマのカスタマイズや、キャッシュプラグインが残っていないか確認してください。このテーマはプラグインなしで動きます。

**写真を変えたのに古い写真が出る**  
ブラウザの再読み込み（スーパーリロード）を試してください。サーバー側のキャッシュがある場合は、そちらも消してください。

**トップページ以外の固定ページ**  
ヘッダーとフッターは同じデザインです。本文だけがシンプルな白いページになります。ホームページ本体のデザインは変わりません。
