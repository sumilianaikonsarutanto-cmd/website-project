========================================
ステルン と ハッピーペイントホーム は別のサイトです
========================================

この GitHub リポジトリは、もともと別件の
「ハッピーペイントホーム（雨漏り修理）」のサイトが入っていました。

ステルンのサイトは後から追加したので、
いちばん上の index.html を開くとハッピーペイントホームが出ます。
ステルンではありません。

----------------------------------------
WordPress に入れるファイル
----------------------------------------
stern.zip

（リポジトリのいちばん上にあります）

入れ方：
1. stern.zip をパソコンに保存する
2. WordPress 管理画面 → 外観 → テーマ
3. 新規追加 → テーマのアップロード
4. stern.zip を選ぶ
5. 今すぐインストール → 有効化

※ STERN_homepage.zip や、GitHubの「Code → Download ZIP」
  （リポジトリ全体）は使わないでください。
  それを入れると「style.css がありません」になります。
